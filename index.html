Módulo 1 — Actualización masiva desde Excel (hoja BASE)

Sube un Excel cuyas columnas A, B y C (desde la fila 2) contengan: A = valor a buscar en la columna A de BASE, B = nuevo valor para la columna S (ESTATUS), C = nuevo valor para la columna P (OBS). No se modifica nada más.

Módulo 2 — Registro de tarjetas nuevas / de otros estados

El Excel debe tener, en este orden de columnas (desde la fila 2): FOLIO, ID SARE, NOMBRE SARE, MUNICIPIO, CCT, NOMBRE ESCUELA, ID BECARIO, NOMBRE BECARIO, PRIMER APELLIDO, SEGUNDO APELLIDO, REMESA, PROGRAMA, BLOQUE, OBS, MES DE REMESA, CURP, ESTATUS.
